Free DHCP tools

Three small utilities that run in your browser. They do not send your input to us, do not set cookies, and do not require an account. Examples use documentation addresses only (192.0.2.0/24, MAC 00:00:5E:00:53:00).

DHCP option decoder

Paste a hex dump of DHCP options (or a full frame) and read message type, lease time, server ID, and the rest.

DHCP scope calculator

From a prefix, get the network, broadcast, usable range, and a recommended DHCP pool to start from.

Wireshark DHCP filter builder

Build a display filter for Discover, Offer, Request, and Ack, plus MAC, server, transaction ID, or VLAN.

These pages decode and calculate. They do not generate clients or a capture. PathProbe Free simulates up to five DHCP clients, can write a pcapng for Wireshark, and never expires.
