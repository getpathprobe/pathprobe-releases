DHCP option decoder

Paste the options section of a DHCP message, or a full BOOTP/DHCP frame. If the magic cookie 63 82 53 63 is present, decoding starts after it. This page never uploads what you paste.

Use documentation addresses in examples and write-ups. Do not paste captures that contain production MAC addresses or hostnames you are not allowed to share.

Need to generate the clients and the pcap, not just decode options? PathProbe Free simulates five DHCP clients and never expires. A run requires --authorized — only test networks you own or are allowed to test.
