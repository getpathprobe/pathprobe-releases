DHCP scope calculator

IPv4 only. Enter an address and a CIDR prefix or a dotted mask. The recommended pool is a starting point — it is not a server configuration, and it does not prove a DHCP server will hand those addresses out.

The sample uses the documentation prefix 192.0.2.0/24 (RFC 5737). Nothing you enter leaves this browser.

A calculator sizes a range. It does not show you Discover, Offer, Request, and Ack. PathProbe Free can simulate five DHCP clients against a server you are authorized to test and write a pcapng for Wireshark.
