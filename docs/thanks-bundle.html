Thank you for buying the Lab Bundle

Your payment went through. Two license keys — one for PathProbe Pro and one for JackedIN — will arrive in a single email within about 15 minutes, sent to the address you used at checkout. Paddle also emails you a receipt (Paddle.com is our reseller, so the charge appears as PADDLE.NET* on your statement).

Each key activates on one computer (non-transferable). You can use them on the same machine or on two different ones.

1. Download

PathProbe: github.com/getpathprobe/pathprobe-releases/releases/latest

JackedIN: github.com/getpathprobe/jackedin-releases/releases/latest

2. Activate PathProbe Pro

Linux (terminal):

sudo pathprobe license activate --key 'PP1....'

Windows (Command Prompt or PowerShell, run as Administrator):

pathprobe license activate --key "PP1...."

Then run pathprobe license status. You should see Tier: pro.

3. Activate JackedIN

In the app: open JackedIN, choose Enter license, paste the key, and choose Activate. From the command line:

jackedin license activate 'JACKEDIN1....'
jackedin license status
