One program: GUI + CLI + API

Run jackedin with no arguments for the desktop window. Run it with a command and it stays in the terminal, prints a result, and exits — ready for scripts and pipes.

$ jackedin ports
$ jackedin connect --serial COM5 --baud 9600
$ jackedin connect --host switch.example.net --user admin
$ echo 'show version' | jackedin connect --protocol telnet --host 192.0.2.10
$ jackedin license status

Serial consoles

DB9 RS-232 and RJ45-to-DB9 console cables. Defaults to 9600 8N1; prefers your USB-serial adapter (FTDI, Prolific, CH340, CP210x).

SSH & Telnet

Passwords, one-time codes, OpenSSH and PuTTY keys, ssh-agent and ~/.ssh/config. Host-key checks that always warn on a changed key.

Source interface

Pick the NIC or source IP for each outgoing connection.

Clean logs, on by default

Readable text logs, even from a Junos-style CR CR LF console. --raw when you need the control codes.

Tabs, sessions, reconnect

Tabs, split panes, a saved-session tree with search, recents — and a dropped session reopens the connect dialog, not a dead black screen.

Network tools

Port scan, session-limit test, other-sessions indicator after SSH login, ping and traceroute.

Wireshark capture

Start a dumpcap capture on connect, including loopback filtered to the session port.

Local API

Automate open, send, scan, ping, traceroute and events from your own scripts on the same machine.

SFTP file transfer is not in this release. Only scan devices you own or are allowed to test.
