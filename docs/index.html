New in 1.2.2ProLinux / Raspberry Pi

Drop a Pi inline. See every packet live in Wireshark.

Turn a Raspberry Pi or any Linux box with two USB NICs into a pass-through network tap. Put it between any two devices, a switch and an AP, a router and a camera, a PLC and its controller, and capture everything that crosses the wire, without touching either device's config.

  • Invisible on the wireA transparent bridge with no IP address. Both devices keep talking as if they were plugged into each other. The built-in NIC stays on management and is never bridged.
  • Capture to file or stream live to WiresharkWrite a pcapng file, or pipe pcapng straight into Wireshark on the same box or over SSH to your workstation. Optional BPF filters.
  • Break it on purposeAdd delay, jitter, loss or a rate limit to the bridge ports with the built-in Linux tc netem. The guide has copy-paste commands.
  • Runs on a Raspberry PiLinux amd64 and arm64, including Raspberry Pi. One tap reset tears it down and restores both NICs, and it works on Free too.

Pro feature, Linux and Raspberry Pi only (not in the Windows build). Needs two USB Ethernet adapters (USB 3 recommended) and dumpcap (package wireshark-common). Only capture on networks you own or are authorized to test.

pi — pathprobe tap
$ sudo pathprobe tap bridge --upstream eth1 --downstream eth2 --mgmt eth0
bridge br-tap up: eth1 upstream, eth2 downstream
$ sudo pathprobe tap capture --stdout 2>tap.log | wireshark -k -i -
# optional: add 100 ms delay with 20 ms jitter on one bridge port
$ sudo tc qdisc add dev eth2 root netem delay 100ms 20ms
$ sudo tc qdisc del dev eth2 root
$ sudo pathprobe tap reset
bridge br-tap removed; eth1 and eth2 restored
What it does

One small binary. A whole test bench.

Everything you reach for when the network "is fine" but nothing works.

DHCP simulation

Simulate DHCPv4/v6 clients with custom MACs to load-test servers, relays and address pools. Up to 5 on Free, up to 1,000 on Pro.

VLAN tagging & QinQ

Run clients on a single 802.1Q tag, or stacked QinQ tags on Pro, to prove trunks and relays end to end.

Inline tap PRO · LINUX/PI

Pass-through bridge with no IP. Capture to pcapng or stream live to Wireshark. See how it works.

Scan & trace

ARP and IPv6 subnet scans, internet check, WAN address lookup and ICMP traceroute bound to the interface you choose.

Packet capture

Save pcapng alongside any test so you can open exactly what happened in Wireshark. Included on Free.

Standards checks & JSON

Flags results that break RFC/IEEE standards. JSON output for scripts and CI; Pro adds extra checks and live events.

Automation & AI agents

MCP server, scheduled profile runs with ntfy/webhook alerts (Pro), NetBox/Nautobot inventory, run log, tab completion.

Interface & link

List adapters, link speed, duplex and addresses. Pick an interface by name or MAC. Static addressing built in.

FAQ

Questions, answered

Is there a graphical interface?

No. PathProbe is command-line only, with no GUI and no API. Run it from a Linux shell, or an Administrator Command Prompt or PowerShell on Windows. pathprobe examples prints a guide for every command.

What do I need for the inline tap?

A Pro license, a Linux computer or Raspberry Pi (amd64 or arm64), two USB Ethernet adapters (USB 3 recommended) and dumpcap (sudo apt install wireshark-common). The built-in NIC stays on management. The tap guide has the diagram and every command. The tap is not in the Windows build.

Can I try it before I buy?

Yes. A computer with no license gets a 72-hour free Pro trial — no email and no card — including the inline tap and live dhcp run --json. After 72 hours the tier is Free. The Free tier never expires and includes all core commands with a 5-client DHCP limit.

How does licensing work?

Pro is a one-time purchase. 1 license = 1 computer, non-transferable. Your key is emailed after purchase (allow up to 1 hour) and needs a one-time online activation. Pro includes updates for all 1.x releases.

Can I get a refund?

All sales are final, no refunds except where required by law, so please try the Free tier first. If you have trouble activating or using your license, email service@getpathprobe.com and we will help. See the Refund Policy.

Who processes my payment?

Paddle.com is our online reseller and Merchant of Record. Paddle handles checkout, payment, sales tax and receipts.

Is there a Mac version?

Not yet. A Mac version is coming soon. Today PathProbe runs on Linux (amd64 and arm64, including Raspberry Pi) and Windows 10/11 x64.

Is it legal to use?

Only test networks you own or are authorized to test. dhcp run requires the --authorized flag to confirm that.
