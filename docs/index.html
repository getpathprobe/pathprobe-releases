PathProbe

A command-line network test tool for Linux and Windows: DHCP client simulation, interface and link checks, subnet scans, traceroute and packet capture.

Command-line only. PathProbe has no graphical interface and no API. You run it from a terminal (Linux shell, or an Administrator Command Prompt/PowerShell on Windows).

Download v1.1.3

$ sudo pathprobe dhcp run --iface eth0 --count 5 --authorized
$ pathprobe interfaces
$ pathprobe traceroute example.com

Simulated DHCP clients on a lab network, ping from the server side, pcapng capture. Captions available. Voiceover is AI-generated.

Features

DHCP simulation

Simulate multiple DHCPv4/v6 clients with custom MACs and VLAN tags to test servers and relays.

Interface & link

List adapters, link speed and addresses; select an interface by name or MAC.

Scan & trace

ARP / IPv6 scan of a subnet, internet check, WAN address lookup and ICMP traceroute bound to an interface.

Standards checks & JSON

Flags results that break RFC/IEEE standards; JSON output and packet capture for scripts.
